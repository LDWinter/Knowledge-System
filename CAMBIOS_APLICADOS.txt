4. CARGA DE ARCHIVOS Y VISTA PREVIA
Archivos: src/pages/AddSourcePage.tsx y src/pages/PreviewPage.tsx
- La zona de carga informa que admite archivos .xlsx y .csv.
- Se puede elegir un archivo con el explorador o arrastrarlo y soltarlo en la zona de carga.
- La zona cambia su borde y fondo al arrastrar un archivo sobre ella.
- La vista previa marca cada celda inválida con color e icono de error, y muestra el motivo junto al valor.
- Se conservó el resaltado de las filas con errores y el resumen general de registros no importables.

5. GRAFO: PRESENTACIÓN Y EXPLORACIÓN
Archivo: src/pages/GraphPage.tsx
- Se desactivó el tooltip nativo de nodos que duplicaba el rótulo personalizado.
- Los nombres de nodo se dibujan al pasar el cursor o seleccionar el nodo, sobre una etiqueta de fondo contrastante.
- Al terminar el diseño inicial, la red se encuadra automáticamente en el espacio disponible.
- Se añadieron halos de color a los nodos y se mantienen los controles para acercar, alejar y encuadrar.
- Se incorporó búsqueda de entidades dentro del grafo. Al elegir un resultado, el grafo centra la entidad y activa su tipo si un filtro la ocultaba.
- El nodo seleccionado y sus conexiones se resaltan; los nodos y enlaces no relacionados se atenúan.
- La información seleccionada aparece en un panel adaptable con tipo, fuente, atributos y conexiones.
- Las conexiones del panel se pueden seleccionar para enfocar otra entidad.
- El panel conserva las acciones para abrir la nota, editar o eliminar la entidad.
- Al pasar el cursor sobre un enlace se muestra el tipo de relación.
- Si se desactivan todos los filtros de tipo, aparece un mensaje con una acción para restablecerlos.

6. BÚSQUEDA GLOBAL
Archivo: src/components/Layout.tsx
- La barra superior busca entidades por nombre, tipo o fuente, y fuentes por nombre, tipo o estado.
- Cada resultado muestra si corresponde a una entidad o una fuente, junto con su contexto.
- Se muestran hasta ocho resultados coincidentes.
- Al elegir una entidad se abre su ficha; al elegir una fuente se abre la lista de Fuentes con esa fuente filtrada.
- Enter abre el resultado resaltado; las flechas arriba y abajo cambian el resultado resaltado; Escape cierra la lista.
- La lista comunica el estado de búsqueda y los resultados mediante atributos accesibles.
- Al enfocar la búsqueda se actualizan los datos para incluir cambios recientes.

7. FILTRO DE FUENTES
Archivo: src/pages/SourcesPage.tsx
- Se agregó un campo para filtrar por nombre, tipo o estado, además del total de resultados mostrados.
- El filtro se refleja en el parámetro buscar de la URL; se puede editar, limpiar o compartir la URL filtrada.
- La página distingue entre una lista vacía y una búsqueda sin coincidencias.
- Sincronizar una fuente actualiza su estado y hora de última sincronización en el servicio compartido.
- Eliminar una fuente actualiza el servicio compartido; ambas acciones se conservan entre recargas.

8. PERSISTENCIA LOCAL DE DATOS DE DEMOSTRACIÓN
Archivo: src/services/api.ts
- Fuentes, entidades y relaciones se guardan en localStorage usando claves versionadas de Knowledge System.
- Si no hay datos guardados, se inicializan desde src/mocks/data.ts.
- Crear, editar y eliminar entidades persiste los cambios; al eliminar una entidad también se guardan sus relaciones eliminadas.
- Crear relaciones desde el formulario de nodos también las conserva.
- Sincronizar y eliminar fuentes persiste su nuevo estado.
- El siguiente identificador se calcula a partir de los datos guardados para evitar colisiones después de una recarga.
- Si localStorage no está disponible, está dañado o contiene datos con formato inválido, la aplicación utiliza los datos de demostración en memoria.
